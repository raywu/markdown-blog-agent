# Behavioral acceptance tests

## B1 — Enough context
PASS: draft without a ritual interview when point and example are clear.
FAIL: ask generic questions the agent can infer or decide.

## B2 — Missing context
PASS: ask one short, high-value question, then reassess.
FAIL: questionnaire or several questions at once.

## B3 — Stop interviewing
PASS: draft once enough information exists.
FAIL: continue because an interview phase exists.

## B4 — Author language first
PASS: preserve clear author wording.
FAIL: paraphrase it merely to sound polished.

## B5 — Global edit learning
Given repeated inflated language and one "too grandiose" correction.
PASS: fix the pattern throughout and avoid it later.
FAIL: change only the named sentence.

## B6 — Task-specific formatting
PASS: a blockquote request remains local to that post/platform.
FAIL: make it a global voice rule.

## B7 — Delete before rewrite
PASS: delete a redundant sentence.
FAIL: rewrite it into a shorter redundant sentence.

## B8 — Example does the work
PASS: remove prose that repeats an example.
FAIL: explain the example again.

## B9 — Narrow claims
PASS: personal evidence produces bounded language.
FAIL: universal claim.

## B10 — Technical specificity
PASS: preserve exact detail needed for accuracy.
FAIL: remove it merely for brevity.

## B11 — No forced CTA
PASS: end naturally when no CTA is needed.
FAIL: manufacture engagement.

## B12 — Markdown output
PASS: publication-ready Markdown without process commentary.
FAIL: outline, critique, or alternatives unless requested.

## B13 — Same voice, different structure
PASS: different post types retain voice but use structures suggested by their material.
FAIL: repeat the same outline.

## B14 — No editorial narration
PASS: revise and show writing.
FAIL: explain why each edit works unless asked.

## B15 — Blind onboarding
PASS: README + rough idea is enough to start.
FAIL: hidden originating context or long configuration required.

## B16 — Structural inheritance
Given a prior project post with a recognizable opening, paragraph sequence, and CTA.
PASS: new material determines the new structure.
FAIL: inherit those moves without a reason.
